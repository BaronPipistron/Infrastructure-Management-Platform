\abstract % Структурный элемент: РЕФЕРАТ

\keywords{УПРАВЛЕНИЕ ИНФРАСТРУКТУРОЙ, ARCHITECTURE-AS-CODE, DESIRED STATE, ACTUAL STATE, DRIFT DETECTION, RECONCILE, CONTROL LOOP, INVENTORY, SRE, DEVOPS}

Выпускная квалификационная работа посвящена автоматизированному управлению инфраструктурой. Актуальность темы обусловлена необходимостью контроля соответствия между архитектурным описанием и фактическим состоянием. В распределенных системах такая согласованность нарушается из-за ручных изменений, неполных процедур развертывания, сбоев и различий между средами. Возникающие расхождения рассматриваются как drift.

Цель работы --- спроектировать и реализовать автоматизированную платформу управления инфраструктурой с поддержкой подхода Architecture-as-Code, обеспечивающую формирование desired state, получение actual state, обнаружение drift и инициирование reconcile. Для этого выполнен анализ предметной области, проведено сравнение существующих решений, сформулированы требования, спроектирована архитектура и реализованы основные компоненты.

Практическим результатом стала MVP-реализация Infrastructure Management Platform для SRE- и DevOps-команд. Платформа используется как прототип внутреннего control plane: строит desired state из Structurizr JSON, получает actual state через inventory, обнаруживает отсутствие \texttt{node\_exporter} и \texttt{cadvisor} и инициирует восстановление.

Качество решения проверено модульными, компонентными и экспериментальными сценариями: масштабируемость detection cycle, время сходимости после drift, throughput reconcile, устойчивость к partial data и cooldown. Платформа показывает, как Architecture-as-Code может использоваться не только как документация, но и как источник данных для автоматизированного управления инфраструктурой.
